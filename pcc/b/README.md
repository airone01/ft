# B

This project aims to create a simple B language compiler, using the `lex` and
`yacc` programs and their syntax.

## Requirements

This project requires **GNU Make**, **yacc** and **lex** (or **bison** and
**flex** as drop-in more modern replacements).

## Monorepo

This project is not integrated in the monorepo through the Zig builder like
other projects because it depends on `yacc` and `lex` to build. I could
intercept the C files generated by those programs and use those, but frankly,
I'm bored to do it.
